TASK-003: Implement RegisterAuraCredentialFlag() helper in common/flags
Date: 2026-05-06T00:00:00Z
================================================================================

Summary:
Added `RegisterAuraCredentialFlag(cmd, cfg)` to `common/flags/flags.go`. The helper adds a
persistent `--credential`/`-c` flag and wraps any existing `PersistentPreRunE` in a chain that
runs the prior hook first, then resolves the named credential from the store and calls
`cfg.Aura.SetActiveCredential`. Binary-specific error hints use `cmd.Root().Use`.
7 unit tests cover all acceptance criteria paths.

Files Changed:
- common/flags/flags.go (modified: added RegisterAuraCredentialFlag)
- common/flags/flags_test.go (created: 7 unit tests covering all hook paths)

Key Decisions:
- Captures `prior := cmd.PersistentPreRunE` before overwriting to enable correct chaining
- Uses `cmd.Flag("credential").Changed` (not value != "") to detect explicit flag setting
- Error message uses plain ASCII comma instead of em dash for codebase consistency
- Binary hint: root.Use == "neo4j-cli" → "neo4j-cli aura credential list"; else → "aura-cli credential list"
