## PR description draft

Linear: CLI-123 (https://linear.app/neo4j/issue/CLI-123/control-neo4j-docker-instances)

Adds a `neo4j-cli docker` command tree (`create / list / get / start / stop / delete`) for managing local Neo4j containers via the docker CLI. Default enterprise eval license (`--accept-license` upgrades to full); port-conflict pre-flight; name-collision auto-suffix; `--ephemeral` + `--env-file <path>` flow into `query --env`; `--wait` via Bolt readiness probe (reuses vendored neo4j-go-driver). Docker is source-of-truth via `org.neo4j.cli.managed=true` labels — no separate state file.

Security review (REQ-NF-004) ran during task-015. Two findings remediated in this PR: the high-severity password leak in `docker run` error messages (added `redactArgs` mask in client.go) and the low-severity pre-existing-file mode issue in `--env-file` writes (added `Chmod 0o600` after write). Both have regression tests.

Docs updated: README "Local Neo4j (Docker)" section, AGENTS.md "Docker Subsystem Notes", skill `description.txt` extended to trigger on docker/local-neo4j phrasing, skill `additions.md` with copy-paste examples for persistent + ephemeral flows.

Website update (REQ-DOC-008) is a separate follow-up — pick it up in the next prompt-driven `gh-pages` refresh.
