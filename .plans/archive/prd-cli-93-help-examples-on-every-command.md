# PRD: CLI-93 — `Example:` blocks on every cobra leaf

## Overview

The Agent CLI audit (§7.1, `agent-cli-auditor.md:454-460`) requires every command's `--help` to carry ≥3 realistic examples. Today only **5** leaf commands have an `Example:` field — `aura instance create`, `query :embed`, `agent-context`, `skill install`, `skill remove`. The remaining ~95 leaves expose flag descriptions only; agents must synthesise invocations from those descriptions, wasting tokens and inviting wrong calls.

This PRD adds `Example:` fields to every cobra leaf in the live `neo4j-cli` tree, normalises the existing five to a uniform style, and locks the rule with a regression test. Examples flow into three surfaces from a single source-side edit: `--help`, the generated SKILL bundle (`references/*.md`), and the `agent-context` JSON tree.

Linear: https://linear.app/neo4j/issue/CLI-93 (parent CLI-71 — audit umbrella).

## Goals

- Every runnable cobra leaf in `neo4j-cli` ships ≥3 realistic, agent-usable examples in `--help`.
- Uniform style — flush-left, backtick raw strings, `neo4j-cli` binary prefix, `#` comments per invocation.
- Regression-safe — a CI gate fails the build if a new leaf lands without an Example.
- Bundle parity — generated SKILL pages and `agent-context` JSON pick the new Examples up automatically.

## Non-Goals

- Rewriting `Short:` / `Long:` strings on commands that already have them.
- Adding Examples to internal/hidden commands, cobra-injected `help` / `completion` subtrees, or the `aura/cmd/main.go` standalone-aura entrypoint (compiled but not shipped).
- Changing the renderer in `common/skill/render/render.go` (its trim-then-fence behaviour is already correct; we conform to it).
- Touching the render fixture in `common/skill/render/testdata/` (synthetic tree, isolated from real commands).
- Adding a separate top-level `examples` command, `--examples` flag, or any new surface — examples live on the `cobra.Command.Example` field only.

## Requirements

### Functional Requirements

- **REQ-F-001**: Every runnable cobra leaf reachable from `app.NewCmd(cfg)` (`neo4j-cli/app/app.go`) has a non-empty `Example:` field.
- **REQ-F-002**: Each Example contains at least 3 distinct invocations, separated by a blank line.
- **REQ-F-003**: Each invocation is preceded by a single `# <description>` comment line on the line immediately above it.
- **REQ-F-004**: Every line of every Example is flush-left (no leading whitespace on any line, including the first).
- **REQ-F-005**: Every invocation uses the binary name `neo4j-cli` (not `neo4j`, not `aura`).
- **REQ-F-006**: Every Example is written as a backtick-delimited raw string literal in Go source (not a `+`-concatenated string with embedded `\n`).
- **REQ-F-007**: Write-annotated commands (those for which `cmd.Annotations["write"] == "true"` — see `common/flags/flags.go:73`) include `--rw` in **every** invocation in their Example block.
- **REQ-F-008**: Read-only commands omit `--rw` from their Examples.
- **REQ-F-009**: At least one invocation per read-only leaf uses `--format json` (agent-friendly form).
- **REQ-F-010**: Placeholder UUIDs / IDs use the literal `00000000-0000-0000-0000-000000000000`.
- **REQ-F-011**: Examples on the five commands that already have them (`aura instance create`, `query :embed`, `agent-context`, `skill install`, `skill remove`) are normalised in-place to satisfy REQ-F-001 through REQ-F-010.
- **REQ-F-012**: A new test `TestAllLeafCommands_HaveExamples` in `neo4j-cli/internal/subcommands/agentcontext/agentcontext_test.go` walks the live cobra tree built by `app.NewCmd(cfg)`, identifies every visible runnable leaf (filtering out hidden commands and cobra-injected `help` / `completion` subtrees so the gate matches what `common/skill/render` puts in the bundle), and asserts for each leaf:
  - `cmd.Example` is non-empty,
  - the first line does not start with `"  "` (flush-left).
  Failure messages identify the command by its full path (e.g. `neo4j-cli aura instance list`).
- **REQ-F-013**: The committed SKILL bundles at `neo4j-cli/internal/skill/bundle/**` and `neo4j-cli/aura/internal/skill/bundle/**` are regenerated by `go generate ./neo4j-cli/internal/skill/... ./neo4j-cli/aura/internal/skill/...` and committed in the same PR.
- **REQ-F-014**: A single `Minor`-kind changelog entry is added under `.changes/unreleased/` describing the user-visible change.
- **REQ-F-015**: The `query` parent command (`neo4j-cli query <cypher>`) — runnable directly even though it has subcommands — also receives an Example block per REQ-F-001 through REQ-F-010. Its Example covers: inline Cypher arg, stdin-piped Cypher, `--param`, `key:embed=<text>` modifier, and `--format json`.
- **REQ-F-016**: The standalone-aura entrypoint at `neo4j-cli/aura/cmd/main.go` (compiled but not shipped) and its standalone tree are NOT in scope; the gate test walks only `app.NewCmd(cfg)`.

### Non-Functional Requirements

- **REQ-NF-001**: `make test`, `make fmt-check`, `make lint`, and `make generate-check` all pass on the resulting tree.
- **REQ-NF-002**: `git diff neo4j-cli/internal/skill/bundle/ neo4j-cli/aura/internal/skill/bundle/` after `go generate` shows ONLY Example-related additions — no unrelated drift in Short, Long, flag descriptions, or ordering.
- **REQ-NF-003**: Generation is deterministic — running `go generate` twice produces identical bundles (covered by existing `TestBundle_Deterministic`).
- **REQ-NF-004**: All new Example strings render correctly across `--help` output, generated SKILL `references/*.md` pages, and `agent-context --format json` (covered indirectly by `TestGenerator_RoundTrip` and the new gate test).
- **REQ-NF-005**: Single PR (not split per subtree).

## Technical Considerations

### Renderer behaviour — why flush-left

`common/skill/render/render.go:235` is:

```go
if e := strings.TrimSpace(cmd.Example); e != "" {
    buf.WriteString("Examples:\n\n")
    buf.WriteString("```\n")
    buf.WriteString(e)
    if !strings.HasSuffix(e, "\n") {
        buf.WriteString("\n")
    }
    buf.WriteString("```\n\n")
}
```

`strings.TrimSpace` strips leading/trailing whitespace from the **entire** string. Indents on line 1 are stripped; indents on lines 2..n are preserved. Examples that follow the cobra 2-space "convention" therefore render as ragged blocks in SKILL pages. AGENTS.md "Cobra Help / Skill Bundle Rendering Notes" documents this. The fix: flush-left every line. The renderer is correct; only command source needs change.

### Global flags already cascade

- `--format` is registered persistently on the root command (`neo4j-cli/app/app.go:40` via `flags.RegisterOutputFlag`). Every subcommand inherits it; Examples can use it freely.
- `--rw` is registered persistently on the root command (`neo4j-cli/app/app.go:41` via `flags.RegisterRwFlag`) and enforced by `flags.EnforceWriteGate` (`common/flags/flags.go:73`) on any command whose `Annotations["write"] == "true"`. Write-command Examples without `--rw` would print but would fail if executed verbatim, defeating the audit's "realistic examples" goal — hence REQ-F-007.

### Per-command Example placement

Slot the `Example:` field on the `cobra.Command` literal between `Long:` and `Args:`/`RunE:`. Example shape (from a write leaf in the Aura tree):

```go
Example: `# Pause an Aura instance
neo4j-cli aura instance pause 00000000-0000-0000-0000-000000000000 --rw

# Pause and wait for completion
neo4j-cli aura instance pause 00000000-0000-0000-0000-000000000000 --await --rw

# Pause and pipe the response for scripting
neo4j-cli aura instance pause 00000000-0000-0000-0000-000000000000 --rw --format json | jq '.data.status'`,
```

### Bundle regeneration

After all source edits:

```
go generate ./neo4j-cli/internal/skill/... ./neo4j-cli/aura/internal/skill/...
```

This regenerates `neo4j-cli/internal/skill/bundle/**` and `neo4j-cli/aura/internal/skill/bundle/**`, both committed. `TestGenerator_RoundTrip` (in `make test`) is the gate that fails on stale bundle.

### Reused utilities (no new helpers)

- `common/flags/flags.go:42` — `RegisterRwFlag`, already global.
- `common/flags/flags.go:18` — `RegisterOutputFlag`, already global.
- `common/skill/render/render.go:235` — Example renderer, unchanged.
- `neo4j-cli/app/app.go` — `app.NewCmd(cfg)`, used by the new gate test to walk the live tree.
- `neo4j-cli/internal/subcommands/agentcontext/agentcontext_test.go:194` — `TestAgentContext_HelpExamples`, generalised into the new test.

### Risks

- **Bundle drift across unrelated edits**: `make generate-check` (`git diff --exit-code` after `go generate`) fails on any uncommitted tracked-file diff. Mitigation: regenerate as the last source-edit step, commit source + bundle + changelog together.
- **Forgotten leaves**: The gate test enumerates every leaf, so a missed file fails CI with the command path in the failure message. Self-correcting.
- **`--rw` enforcement surprises**: Examples on write commands without `--rw` would compile fine but exit non-zero at runtime, violating REQ-F-007's "realistic" intent. The gate doesn't catch this — reviewer responsibility.
- **Cobra `help` / `completion` subtrees**: Auto-injected by cobra, would be flagged by a naive walker. Filter must mirror `common/skill/render`'s visibility filter.

- [ ] Every visible runnable leaf under `app.NewCmd(cfg)` has a non-empty `Example:` field.
- [ ] Every Example has ≥3 invocations, each preceded by a `# comment` line; blank line between invocations.
- [ ] Every Example line is flush-left.
