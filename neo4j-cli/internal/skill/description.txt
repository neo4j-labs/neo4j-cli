Runs Cypher and manages Neo4j Aura, Neo4j connection (dbms) credentials, and embedding-provider credentials from the terminal via the neo4j-cli CLI. Use when the user wants to execute or pipe Cypher against Neo4j, embed text inline as a Cypher parameter, introspect a schema, list/create/get/delete/provision/resize Aura instances or tenants, manage Aura/dbms/embed credentials, install/remove the neo4j-cli skill in an agent, or self-update the neo4j-cli binary via `neo4j-cli update`. Skip for Cypher syntax questions, graph data modeling, Neo4j drivers, Docker/Kubernetes, Neo4j Browser, or other databases.
