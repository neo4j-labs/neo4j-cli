quickstart

From zero to graph in 60 seconds.

New to Neo4j? AuraDB has a free tier — no credit card.

Install the CLI

Pick your platform from the install tabs above, or use the one-liner for your OS.

$ curl -sSfL https://neo4j.sh/install.sh | bash
2

Install the skill

Teaches Claude Code, Codex, Cursor, and all others how to drive the CLI. ↓

$ neo4j-cli skill install --rw
3

Add Aura credentials

Grab a client ID + secret from your Aura account and register them. ↓

> Add my Aura credentials — grab client ID and secret from console.neo4j.io→ loading skill neo4j-cli$ neo4j-cli credential aura-client add --name "default" --rw ...
4

Create an instance

Provision a new Aura instance. Free tier needs no credit card. ↓

> Create a free Aura instance called movies-dev in us-east-1→ loading skill neo4j-cli$ neo4j-cli aura instance create --name "movies-dev" --type free-db ...
5

Insert data

Pass typed params inline with --param, or pipe a Cypher file. ↓

> Insert 3 Person nodes: Alice born 1990, Bob 1985, Carol 1992→ loading skill neo4j-cli$ neo4j-cli query --rw 'UNWIND $p AS r CREATE (:Person …)' --param 'p=[…]'
6

Query your database

Run Cypher against any Neo4j. Pretty table by default; JSON when piped. ↓

> Find all people born before 1990 and return their names→ loading skill neo4j-cli$ neo4j-cli query 'MATCH (p:Person) WHERE p.born < 1990 RETURN p.name, p.born'

Pipe Cypher in, JSON out — params, files, scripts 
> Seed the database from seeds/people.cypher, then show me the 3 youngest people as JSON→ loading skill neo4j-cli
# pipe a cypher file (--rw for writes)
$ neo4j-cli query --rw < seeds/people.cypher

✓  247 rows affected · 84ms

# pipe result to jq to filter and reshape
$ neo4j-cli query \
    'MATCH (p:Person) RETURN p.name AS name, p.born AS born ORDER BY p.born DESC LIMIT 3' \
    | jq '.rows[] | {name, born}'

{"name": "Carol", "born": 1992}
{"name": "Alice", "born": 1990}
{"name": "Bob",   "born": 1985}

# inline params instead of a file
$ neo4j-cli query --rw \
    'UNWIND $p AS r CREATE (:Person {name:r.name,born:r.born})' \
    --param 'p=[{"name":"Alice","born":1990},{"name":"Bob","born":1985}]'

# connection via env or .env (auto-discovered)
$ NEO4J_URI=neo4j+s://f1ab…b2.databases.neo4j.io \
  NEO4J_PASSWORD=$AURA_PW \
  neo4j-cli query 'MATCH (n) RETURN count(n)'

Installation & Update

Install with curl (macOS / Linux) or PowerShell (Windows):

$ curl -sSfL https://neo4j.sh/install.sh | bash
# PowerShell:  irm https://neo4j.sh/install.ps1 | iex
# Homebrew:    brew install neo4j-labs/tap/neo4j-cli
# npm:         npm install -g @neo4j-labs/cli
# PyPI/pipx:   pipx install neo4j-cli

Self-update:

$ neo4j-cli update                    # latest stable
$ neo4j-cli update check              # report availability, exit 1 if newer
$ neo4j-cli update --pre-releases     # opt into alpha/beta/rc tags
$ neo4j-cli update --version v1.0.0   # pin or downgrade

Verify: neo4j-cli --help. Installed skill bundles are refreshed automatically whenever the binary version changes (disable with neo4j-cli config set skill-auto-refresh false).

Prefix any installer with NEO4J_CLI_AUTO_INSTALL_SKILL=1 to auto-run skill install --rw after the binary is placed — supported on curl, PowerShell, Homebrew, and npm. Strictly opt-in; omit the prefix to skip skill installation.

Credentials

Three credential types share add / list / use / remove. All are stored in credentials.json under your OS config directory.

aura-client — Aura Console API (client ID + secret). Required for any aura … command.

$ neo4j-cli credential aura-client add --name prod --client-id <id> --client-secret <secret> --rw
$ neo4j-cli credential aura-client use prod

dbms — Neo4j Bolt connection profiles (URI, username, password, database). When a default exists, query connects without flags.

$ neo4j-cli credential dbms add --name prod --uri neo4j+s://… --username neo4j --password <pw> --rw
$ neo4j-cli credential dbms set-embed prod openai-shared   # link an embed credential
$ neo4j-cli credential dbms use prod

embed — Embedding providers (openai / ollama / huggingface). Consumed by --param NAME:embed=… and query :embed.

$ neo4j-cli credential embed add --name openai-shared --provider openai --model text-embedding-3-small --api-key <key> --rw
$ neo4j-cli credential embed use openai-shared
Querying Neo4j

Run Cypher via the Bolt protocol. With a stored dbms credential, no connection flags are needed.

$ neo4j-cli query 'MATCH (n) RETURN count(n) AS n'
$ echo 'MATCH (n) RETURN count(n)' | neo4j-cli query    # stdin
$ neo4j-cli query :schema                             # schema introspection
$ neo4j-cli query … --format json                    # {columns, rows, truncated}
$ neo4j-cli query … --max-rows 500 --truncate-arrays-over 0
$ neo4j-cli query 'RETURN $ids' --param 'ids=[1,2,3]'  # JSON-typed param

Connection resolution (highest first): --uri / --username / --password / --database flags → env vars (NEO4J_URI, NEO4J_USERNAME, NEO4J_PASSWORD, NEO4J_DATABASE) → .env (walks up to git root) → stored dbms credential → built-in defaults (neo4j://localhost:7687, user neo4j, db neo4j).

http:// and https:// URIs are auto-rewritten to neo4j:// and neo4j+s://. For self-signed certs use neo4j+ssc://.

Vector Embeddings

Bind a vector inline with --param NAME:embed=text — text is sent to the configured provider and the resulting []float32 is bound as $NAME for both EXPLAIN preflight and the real query.

$ neo4j-cli query --param 'q:embed=sci-fi movies' --param k=5 \
  "CALL db.index.vector.queryNodes('idx', \$k, \$q) YIELD node, score RETURN node.title, score"

$ neo4j-cli query :embed "hello world" --format json   # standalone, no DB needed

Providers and defaults: openai (api.openai.com/v1) · ollama (localhost:11434, no key) · huggingface (serverless; set --embed-base-url for dedicated endpoint).

Settings resolution (highest first): flag (--embed-provider, --embed-model, …) → env (NEO4J_EMBED_PROVIDER, NEO4J_EMBED_MODEL, …) → .env → stored embed credential → provider defaults.

API-key priority: OPENAI_API_KEY / HF_TOKEN → NEO4J_EMBED_API_KEY → .env → stored credential. One --credential dbms can drive both connection and embedding when the dbms profile carries an embed link.

Aura Management

Requires an aura-client credential. Get client ID + secret from Aura Account Settings.

$ neo4j-cli aura tenant list
$ neo4j-cli aura instance list --format table
$ neo4j-cli aura instance get <id>
$ neo4j-cli aura instance create --name my-db --type free-db --tenant-id <tid> --rw
$ neo4j-cli aura instance create --name prod --type professional-db \
    --cloud-provider aws --region us-east-1 --memory 4GB \
    --tenant-id <tid> --wait --rw
$ neo4j-cli aura instance delete <id> --rw

instance create auto-stores DB credentials as a dbms credential named <instance-id>-default so query connects immediately. Pass --no-credential-storage to skip.

Write Gate (--rw)

All state-mutating commands require --rw. Without it, neo4j-cli query runs EXPLAIN first and blocks mutating Cypher before execution.

$ neo4j-cli query 'CREATE (:Person {name:"Alice"})' --rw
$ neo4j-cli aura instance delete <id> --rw
$ neo4j-cli config set telemetry false --rw

--rw is auto-applied on an interactive TTY. It must be set explicitly for:

  • Agent harnesses — Claude Code, Cursor, Codex, Gemini CLI, Windsurf, Replit, Goose, Devin, Kiro, and others detected by env var (see unjs/std-env).
  • Non-interactive scripts — CI, piped invocations, redirected stdout, nohup.

Disable telemetry without writing config: DO_NOT_TRACK=1 neo4j-cli …

Agent Skills

Installs the embedded skill bundle (SKILL.md + per-subcommand references) into each detected agent's skill directory so agents know the full CLI API without guessing.

$ neo4j-cli skill install --rw             # all detected agents
$ neo4j-cli skill install claude-code --rw  # target one agent
$ neo4j-cli skill list                      # per-agent install state
$ neo4j-cli skill check                     # version drift vs running binary
$ neo4j-cli skill remove [agent]            # idempotent

Supported agents: Claude Code, Cursor, Windsurf, Copilot, Gemini CLI, Cline, Codex, Pi, OpenCode, Junie.

Installed skill bundles are refreshed automatically in the background whenever the binary version changes (after neo4j-cli update, a Homebrew/npm/pipx upgrade, or any other in-place swap). Opt out with neo4j-cli config set skill-auto-refresh false --rw. The bundle covers Aura, Bolt queries, schema introspection, embeddings, credentials, and the write gate — everything agents need to drive the CLI correctly.
