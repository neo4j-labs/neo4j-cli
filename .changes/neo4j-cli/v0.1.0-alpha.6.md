## v0.1.0-alpha.6 - 2026-05-06
### Minor
* Add 'credential dbms' commands (add, list, use, remove) and integrate stored dbms credentials into 'query' connection resolution via the '--credential' flag
* Stop building and releasing the standalone aura-cli binary; the `neo4j-cli aura` subcommand is the replacement
* Require --rw flag for any write operation; query run now uses the Neo4j Bolt driver (--insecure is removed; use neo4j+ssc:// for self-signed certs)
