## v2.0.0 - 2026-05-28
### Major
* BREAKING: 'neo4j-cli skill install <agent>' no longer accepts a positional agent name — use --agent <name> instead. New: install any skill from the curated neo4j-contrib/neo4j-skills catalog, plus --all, --refresh, and a new 'skill refresh' leaf.
### Minor
* Removed deprecated --await alias; --wait is now the only spelling (CLI-111).
