## v1.17.0 - 2026-10-15
### Minor
* New commands for managing projects and tags in a local Neo4j Desktop 2 install: `desktop project list/create/update/delete` and `desktop tag list/create/update/delete` manage the Desktop project and tag catalogs. Create and update print the changed entry, failing with an error if Desktop's returned catalog state lacks it; delete prints a minimal confirmation envelope (`id` and `deleted: true`). The new `desktop dbms update` command renames a DBMS, edits its description, or replaces its project/tag assignments. `desktop connection update` gains matching `--project`/`--tags` flags; both take project/tag names or UUIDs (repeatable/comma-separated) with replace semantics, and an empty value clears the assignments. In `desktop` JSON output, the `project` field on DBMS and connection objects is renamed to `projects` and is now an array instead of a single string. On Desktop versions too old to have the projects/tags endpoints, these commands fail with a clear message telling the user to upgrade Neo4j Desktop 2.
* agent-context now prints a compact command index (about 18 KB instead of about 465 KB) by default; pass a command path (e.g. `agent-context aura instance list`) for that command's details, or --full for the previous complete tree. schema_version is now 2 and `commands` is a flat list of path/short entries by default.
### Patch
* Unknown flags and unknown commands now print the error, a one-line usage and a `Run '<command> --help'` hint instead of the full help text with all examples.
* Fixed `desktop list` and `desktop connection list` failing against Neo4j Desktop 2.3, which reports a connection's `createdAt` as a numeric timestamp instead of a string.
* On Windows, `skill install`, `skill list`, `skill remove` and `skill check` now detect installed agents when the `HOME` environment variable is unset (home is resolved from `%USERPROFILE%`), so `skill install --all` works for Codex users (bundled with ChatGPT Desktop on Windows).
