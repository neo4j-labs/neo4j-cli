## v1.3.0 - 2026-05-15
### Minor
* Setting NEO4J_CLI_AUTO_INSTALL_SKILL=1 before installing via npm, Homebrew, or the curl installer now automatically runs `skill install --rw` after binary placement; the feature is strictly opt-in and any failure is suppressed so the install always succeeds.
* The neo4j-cli skill is now automatically refreshed in the background when the binary version changes, so agents always get up-to-date tool documentation without manual reinstall. Auto-refresh can be disabled via `neo4j-cli config set skill-auto-refresh false`.
